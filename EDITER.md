# Modifier NDL OS sans Codex

## Ouvrir le projet
1. Installe Cursor : https://cursor.com/download
2. Dans Cursor, clique sur **Clone repository**.
3. Colle `https://github.com/ayedonai/ndl-os.git`.
4. Ouvre le dossier téléchargé.

## Où modifier
- Texte, couleurs et mise en page : les fichiers `index.html`.
- Éditeur vidéo : `studio-hygiene/nail-cam/montage/index.html`.
- Les pages sont rangées dans `studio/` et `studio-hygiene/`.

## Publier tes changements sur GitHub
Dans Cursor : onglet **Source Control** → écris un message → **Commit** → **Sync / Push**.

## Important
Le lien actuel en `.chatgpt.site` ne se met pas à jour automatiquement quand tu modifies GitHub : c’est une copie indépendante.
Pour publier toi-même depuis GitHub, active GitHub Pages dans **Settings → Pages**, source **Deploy from a branch**, branche `main`, dossier `/(root)`.
